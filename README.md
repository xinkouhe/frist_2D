# frist-2d

Godot 官方 2D 教程的练习项目。

目前已完成第一个可玩版本：玩家可以移动、持续发射子弹并击杀敌人，击杀敌人获得积分，积分达到一定数量后恢复生命值。

## 操作说明

* `WASD`：移动
* `Shift`：开火
* `Space`：暂停
* `Enter`：快捷开始
* `Esc`：退出游戏

## 游戏规则

* 击杀敌人获得 1 分。
* 每获得 10 分，恢复 1 点生命值。
* 生命值不会超过最大值。
