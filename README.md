## 操作说明

* `WASD`：移动
* `Shift`：开火
* `Space`：暂停
* `Enter`：快捷开始
* `Esc`：退出游戏

## 游戏规则

* 积分随时间增长。
* 每当积分达到 10 的倍数，恢复 1 点生命值。
* 生命值不会超过最大值。
